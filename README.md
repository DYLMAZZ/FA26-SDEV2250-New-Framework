# Basic Angular Invoice App

## Requirements

To run this application, you need:

- Node.js (LTS version)
- npm (Node Package Manager)
- Angular CLI

## Installation

1. Clone or download the project.
2. Open the project folder in a terminal.
3. Install the project dependencies:

```bash
npm install
```

4. If Angular CLI is not installed, install it using:

```bash
npm install -g @angular/cli
```

## Installation
1. CD into the Invoice-App folder
```bash
cd Invoice-App
```

2. run the app and open it in http://localhost:4200/ with this:
```bash
ng serve --open
```
